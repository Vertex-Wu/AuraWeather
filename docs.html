开发者文档

从源码构建纯净的 AuraWeather Windows 桌面终端。

1. 环境依赖

本项目使用纯 C++ (Win32) 编写，依赖 OpenSSL 处理 HTTPS 请求。请确保你的系统为 Windows 10/11 64 位，并安装以下工具链：

  • 编译器：MSYS2 (UCRT64) 或 MinGW-w64
  • 第三方库：OpenSSL 静态库

在 MSYS2 终端中安装 OpenSSL：

pacman -S mingw-w64-ucrt-x86_64-openssl

2. 编译项目

克隆仓库并执行一键构建脚本，编译完成后将生成无依赖的独立 exe 文件。

git clone https://github.com/Vertex-Wu/AuraWeather.git
cd AuraWeather
./build.bat

3. 打包安装程序 (可选)

如需自行生成安装包，请先下载安装 Inno Setup，然后在项目根目录编译 installer.iss 即可。
